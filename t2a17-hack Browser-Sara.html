Welcome to My Browser Object Explorer

Explore your web browser and discover its hidden objects, classes, properties, and methods using JavaScript. Different browsers may produce different results.

What can you explore?

  • Window: Browser window information.
  • Document: Information about the webpage.
  • Images: Image properties and styling.
  • Forms: Text fields and form objects.
  • Navigator: Browser identification information.

Browser Object Comparison

Object What it does Example property
window Controls the browser window innerWidth
document Represents the webpage title
navigator Provides browser information userAgent
screen Provides screen information width
history Provides browser history methods length
Image Represents an image element naturalWidth
