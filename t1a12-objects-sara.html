Local vs Global Variables Notes

Question: Why might it be best to declare the objects in the script tag?

Answer: If you put your objects right in the main script tag instead of hiding them inside a button or function, they become global. That means any button or function on the whole page can use them without issues. If you make them local inside just one function, they disappear as soon as that function is done running, so other buttons won't be able to see them.
